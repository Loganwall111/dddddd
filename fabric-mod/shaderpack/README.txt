SIFT CINEMATIC 0.2 — original experimental Iris shader pack
Select Sift-Cinematic-0.2 in Video Settings > Shader Packs with compatible Iris installed.
A Sift-only world-direction procedural ribbon sky changes with the shared day/night clock.
Cyan/green ribbons, rose dusk, indigo night, colour-preserving screen-space bloom and haze.
Other dimensions retain their original sky; the subtle composite grade remains global.
This is not ray tracing, true volumetric light or physically coloured block lighting.
Set ribbon intensity/speed to zero to disable ribbons or their motion.
The Fabric mod copies this versioned zip only if absent. It never changes shader settings.
No reference pixels or external shader source are included. This alpha is not GPU-validated.
