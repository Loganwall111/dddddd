# Repository

Two separate games live here. They share nothing.

## `multiverse/` — THE MULTIVERSE (standalone game)

An original open-worlds game: escape a dead Earth inside **LODEMUS**, the machine
that keeps the last of humanity alive across realities, and explore five
realities of the **Multiverse** dreamed into being by the god **Simolysis**.

- Cinematic five-chapter intro film with original narration (`public/audio/intro/`)
- 3D holographic main menu with a living spiral galaxy
- Realities: Verdant Expanse (valleys, cliffs, waterfalls, day/night, weather,
  rainbows, aurora, wavy reflective ocean + dive-underwater mirror world),
  the White Void (floating islands), the Infinite Halls (backrooms),
  Fractaline (recursive maze), the Singularity (black hole + accretion disk)
- Gateway portals between realities; progress persists locally

```bash
cd multiverse
npm install
npm run dev     # http://localhost:5173
```
